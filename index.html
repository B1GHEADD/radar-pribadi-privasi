Radar Pribadi: Privacy Policy

Last updated: 1 November 2026 · Versi Bahasa Indonesia di bawah

EnglishBahasa IndonesiaData deletion / Hapus data

1. Who we are

"Radar Pribadi" is a private, single-operator research tool run by bigheaad_ (the "operator"). It is not offered to the public and has no end users other than the operator. Contact: cresti2468@gmail.com.

2. What the app does

The app uses the official Threads API in a strictly read-only way. It searches public Threads posts by keyword (for example, topics in finance, anime, games and film) a few times per day, and summarises how often topics and terms appear over time, so the operator can see which niches and topics are rising or falling. The app never posts, replies, likes, follows, reposts or sends messages on Threads, and it takes no action on any account.

3. Data we handle

  • Operator account data: the Threads user ID and username of the operator's own account, and the access token issued to the app for that account. The token is stored only in a protected configuration file on the operator's private server.
  • Public post data returned by keyword search: post ID, text, public permalink, timestamp, media type, the public username of the author, and public engagement counts when the API provides them. Author usernames are used only to count how many distinct accounts discuss a keyword per day.
  • Usage data: counts of API requests made per day, used to stay within rate limits.

We do not collect private posts, direct messages, contact lists, precise location, or any data from people who have not made their posts public.

4. How we use the data

Data is used only to produce aggregated statistics per keyword and niche (post volume per day, rising terms, trend direction). We do not profile, rank or build records about individual people, we do not contact the authors of posts, and we do not use the data for advertising, surveillance, credit, employment, insurance or housing decisions. We do not use Threads data to train machine-learning models.

5. Sharing

We do not sell, rent, license or share Threads data with any third party. Data is stored on a private server controlled by the operator and is not published.

6. Retention

Collected post data is automatically deleted after 60 days. Aggregated counts that cannot identify a person or a post may be kept longer.

7. Security

The server is private (no public access to the application), the access token is stored in a file readable only by the service account, and tokens are never written to logs or shown in the user interface.

8. Data deletion

You may ask for data about you to be deleted at any time:

  • Remove the app: in Threads, open Settings → Account → Website permissions and remove "Radar Pribadi". The app's access token stops working immediately.
  • Ask us to delete stored data: email cresti2468@gmail.com with your Threads username (for stored posts) and we will delete matching records within 30 days and confirm by email.

9. Children

The app is not directed to children and does not knowingly collect data from anyone under 13.

10. Changes

If this policy changes, the new version will be published at this address with an updated date.

Kebijakan Privasi (Bahasa Indonesia)

Terakhir diperbarui: 1 November 2026

Siapa kami. "Radar Pribadi" adalah alat riset pribadi yang dijalankan satu pengelola, bigheaad_. Alat ini tidak ditawarkan ke publik dan tidak punya pengguna selain pengelola. Kontak: cresti2468@gmail.com.

Apa yang dilakukan. Aplikasi memakai API resmi Threads hanya untuk membaca. Aplikasi mencari postingan publik Threads berdasarkan kata kunci (misalnya topik keuangan, anime, game, dan film) beberapa kali sehari, lalu merangkum seberapa sering topik dan istilah muncul dari hari ke hari, supaya pengelola tahu niche dan topik mana yang naik atau turun. Aplikasi tidak pernah memposting, membalas, menyukai, mengikuti, me-repost, atau mengirim pesan di Threads.

Data yang diproses. (1) ID dan username akun Threads milik pengelola, serta token akses yang diberikan kepada aplikasi, disimpan hanya di berkas konfigurasi terlindungi pada server pribadi. (2) Data postingan publik dari pencarian kata kunci: ID, teks, tautan publik, waktu, jenis media, username publik penulis, dan angka interaksi publik bila tersedia; username penulis hanya dipakai untuk menghitung berapa akun berbeda yang membahas suatu kata kunci per hari. (3) Jumlah permintaan API per hari untuk menjaga batas pemakaian. Kami tidak mengumpulkan postingan privat, pesan langsung, daftar kontak, atau lokasi presisi.

Penggunaan. Data hanya dipakai untuk statistik gabungan per kata kunci dan niche. Kami tidak membuat profil atau catatan tentang individu, tidak menghubungi penulis postingan, tidak memakai data untuk iklan atau keputusan tentang seseorang, dan tidak memakai data Threads untuk melatih model pembelajaran mesin.

Berbagi dan penyimpanan. Data tidak dijual, disewakan, atau dibagikan kepada pihak ketiga. Data disimpan di server pribadi dan otomatis dihapus setelah 60 hari. Hitungan gabungan yang tidak dapat mengidentifikasi orang atau postingan boleh disimpan lebih lama.

Penghapusan data. Cabut akses lewat Threads: Pengaturan → Akun → Izin situs web, lalu hapus "Radar Pribadi"; token langsung tidak berlaku. Untuk meminta penghapusan data tersimpan, kirim email ke cresti2468@gmail.com dengan username Threads-mu; kami menghapus catatan terkait dalam 30 hari dan mengonfirmasi lewat email.
